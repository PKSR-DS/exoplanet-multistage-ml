# Ethics, data protection, and licensing

- Public scientific datasets (NASA Kepler & Exoplanet Archive) — anonymised, research licences apply.
- No personal/sensitive data processed; no human participants or user testing.
- Results are reproducible; code + configs provided. 
- Storage: large raw data kept outside the repo; only small samples/derived artefacts included here.

This aligns with UH guidance to include an ethics section in the FPR and to ensure data meet GDPR and UH policy.
