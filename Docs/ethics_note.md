# Ethics, data use & protection, and licensing
- All datasets are public scientific datasets (NASA/Exoplanet Archive).  
- No personal or sensitive data are processed; no human participants.  
- Data are used for research/educational purposes; cite original sources in the report.  
- Large raw data are kept outside the repo to avoid accidental re-distribution.  
- Outputs are reproducible from code and configs; random seeds fixed where appropriate.
